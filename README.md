# Naveen Boggarapu — Portfolio

A responsive, interactive portfolio for Naveen Boggarapu, AI Software Engineer.

## What's included

- `index.html` — complete website, including styles and interactivity
- `assets/naveen-portrait-sketch.webp` — sketch based on Naveen's photo
- `assets/Naveen_Boggarapu_Resume.pdf` — downloadable resume
- `.nojekyll` — helps GitHub Pages serve the static site as-is

## Publish with GitHub Pages

1. Create a new **public** repository, such as `naveen-portfolio`.
2. Upload everything **inside this folder** to the repository root. Keep the `assets` folder intact.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select **main** and **/(root)**, then save.
4. GitHub will show the published URL on the Pages settings screen.

For local preview, open `index.html` in a browser. The portfolio contains only static files and needs no installation.
